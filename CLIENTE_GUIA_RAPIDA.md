## 🎯 ¿Qué es FASE 14?

FASE 14 es un **sistema automático que gestiona tu proceso de ventas completo**:

✅ Genera propuestas automáticas  
✅ Envía emails de seguimiento  
✅ Predice qué clientes van a cerrar  
✅ Compara qué emails funcionan mejor  
✅ Todo sin que tengas que hacer nada manual  

---

## 🚀 5 Funciones Principales (En 2 minutos)

### 1️⃣ El Dashboard
**¿Qué es?** Tu panel principal donde ves todo lo que está pasando  
**¿Cómo usarlo?**
- Abre http://localhost:8000
- Ves tu lista de clientes
- Ves dónde está cada uno en el pipeline (Prospecto → Cerrado)

---

### 2️⃣ Pipeline de Ventas
**¿Qué es?** Las 4 etapas de una venta:

```
PROSPECTO          PROPUESTA           NEGOCIACIÓN        CERRADO
(Cliente nuevo)    (Propuesta enviada)  (Discutiendo)    (Listo para cobrar)
```

**¿Cómo usarlo?**
- Arrastra clientes entre columnas
- O el sistema los mueve automáticamente cuando haces acciones

---

### 3️⃣ Predicciones ML
**¿Qué es?** Sistema que dice "Este cliente tiene 85% probabilidad de cerrar"  
**¿Cómo usarlo?**
- Mira el % de probabilidad en la tarjeta del cliente
- Números altos (80+) = Probabilidad alta de cerrar
- Números bajos (30-) = Necesita más seguimiento

---

### 4️⃣ Emails Automáticos
**¿Qué es?** El sistema envía emails sin que hagas nada  
**¿Cómo funciona?**
- Día 1: Envía propuesta
- Día 2: Recordatorio automático
- Día 4: Segundo recordatorio
- Día 7: Último seguimiento

---

### 5️⃣ A/B Testing de Emails
**¿Qué es?** Comparar 2 versiones de email para ver cuál funciona mejor  
**¿Cómo usarlo?**
1. Creas un test: "Email A" vs "Email B"
2. El sistema manda cada uno a la mitad de clientes
3. Después te dice: "Email A tuvo 15% de apertura, Email B tuvo 20%"
4. Usas el ganador para todos

---

## 🎮 Tutorial Rápido (5 minutos)

### Paso 1: Ver tu Dashboard
1. Abre http://localhost:8000
2. Verás una lista de clientes
3. Cada cliente tiene:
   - Nombre
   - Estado (Prospecto/Propuesta/etc)
   - Probabilidad de cierre (%)
   - Fecha de última acción

---

### Paso 2: Ver el Pipeline Completo
1. En el menú, busca "Pipeline" o "Embudo de Ventas"
2. Verás 4 columnas: Prospecto → Propuesta → Negociación → Cerrado
3. Cada cliente está en una columna
4. Puedes arrastrarlo a otra columna si cambia estado

---

### Paso 3: Crear un Test A/B de Email
1. Busca "Tests A/B" o "Email Tests"
2. Haz clic en "Crear Nuevo Test"
3. Llena:
   - Nombre: "Test de Follow-up Mayo"
   - Email A: "¿Tienes preguntas?"
   - Email B: "¿Podemos charlar?"
4. Haz clic en "Iniciar"
5. **Eso es todo.** El sistema hace el resto

---

### Paso 4: Ver Predicciones
1. Busca "Predicciones" o "ML"
2. Verás un gráfico circular
3. Ese % es la probabilidad de que el cliente cierre
4. Si es mayor a 70% = Buen momento para hacer follow-up

## ❓ Preguntas Frecuentes

### ¿Cómo agrego un cliente nuevo?
**Respuesta:** Clic en "Agregar Cliente" y llena el formulario.  
El sistema hace el resto automáticamente.

### ¿Dónde veo los emails que se enviaron?
**Respuesta:** En "Histórico" o "Logs" - ves cada email enviado, cuándo, si se abrió, etc.

### ¿Los emails se envían de verdad?
**Respuesta:** Sí, si configuraste correctamente tu email (Gmail, Office365, SendGrid).  
Si no, el sistema simula el envío para practicar.

### ¿Puedo editartodo manualmente?
**Respuesta:** Sí, todo es editable. El sistema también automatiza, pero tú siempre tienes control.

### ¿Qué pasa si cierro el navegador?
**Respuesta:** Los datos se guardan. Cuando vuelves a abrir, todo está igual.

### ¿Funciona en celular?
**Respuesta:** Sí, totalmente responsive. Abre desde tu celular y verás la interfaz adaptada.
