## 📞 SOPORTE Y TROUBLESHOOTING

### Si algo falla:
1. **Primero:** `DEPLOYMENT_GUIDE.md` → Troubleshooting
2. **Luego:** Revisa logs en `/var/log/felix/error.log`
3. **Finalmente:** Reinicia servicio: `sudo systemctl restart felix-api`

### Errores comunes:
- "Connection refused": Verificar PostgreSQL activo
- "Port 8000 in use": Otro proceso usando el puerto
- "Permission denied": Verificar permisos de archivos
