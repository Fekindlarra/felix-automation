🎨 ARQUITECTURA DEL SISTEMA
═══════════════════════════════════════════════════════════════════════════════════

CLIENTE → MAIN ORCHESTRATOR → 9 PASOS → RESULTADOS

Paso 1: AUDITORÍA
  MultiPlatformAuditorAgent
    ├─ Web Auditor (Performance, Security, Tracking)
    ├─ Facebook Ads Auditor (Estructura, Targeting, Content)
    └─ Google Ads Auditor (Keywords, Quality Score, Tracking)

Paso 2: SCORING
  LeadScorerAgent
    └─ Calcula score 0-100 basado en auditorías

Paso 3: PROPUESTAS
  ProposalGeneratorAgent
    └─ Genera HTML + PDF personalizado

Paso 4: EMAILS
  EmailSenderAgent
    └─ Envía via SendGrid (o DEMO MODE)

Paso 5: FOLLOW-UPS
  FollowUpAgent
    └─ Secuencias automáticas (Día 2, 4, 7)

Paso 6: PIPELINE
  SalesPipelineAgent
    └─ Actualiza etapa (Prospecto → Propuesta)

Paso 7-9: DASHBOARDS + REPORTES
  FunnelManagementAgent
    └─ Genera visualizaciones y reportes
