📊 FLUJO DE DATOS COMPLETO
═══════════════════════════════════════════════════════════════════════════════════

    ENTRADA: Lista de IDs de clientes
        ↓
    PASO 1: AUDITORÍA MULTI-PLATAFORMA
    ├─→ audit_client(client_id, platforms=['web', 'facebook_ads', 'google_ads'])
    ├─→ Crea auditorías en BD para cada plataforma
    └─→ Retorna: audit_result con scores

    PASO 2: LEAD SCORING
    ├─→ score_lead(client_id)
    ├─→ Obtiene auditorías del cliente
    └─→ Retorna: overall_score (0-100)

    PASO 3: GENERACIÓN DE PROPUESTAS
    ├─→ get_client_audits(client_id) → obtener IDs
    ├─→ generate_proposal(client_id, audit_ids)
    ├─→ Genera HTML + PDF
    └─→ Retorna: proposal_id

    PASO 4: ENVÍO DE EMAILS
    ├─→ send_proposal(client_id, proposal_id, proposal_data)
    ├─→ Envía via SendGrid (o DEMO MODE)
    └─→ Registra en BD

    PASO 5: FOLLOW-UP SEQUENCES
    ├─→ start_followup_sequence(client_id, proposal_id)
    ├─→ Inicia secuencia de 3 emails (día 2, 4, 7)
    └─→ Retorna: sequence_id

    PASO 6: ACTUALIZAR PIPELINE
    ├─→ move_client_to_stage(client_id, stage=2)
    ├─→ Mueve cliente a etapa PROPUESTA
    └─→ Actualiza embudo

    PASO 7: DASHBOARDS
    ├─→ get_dashboard_data_interno()
    ├─→ get_dashboard_data_cliente(client_id)
    ├─→ get_pipeline_metrics()
    └─→ Genera datos para visualización

    PASO 8-9: REPORTES Y RESUMEN
    ├─→ Genera reportes en JSON
    ├─→ Exporta analytics
    └─→ Guarda resumen de ejecución

    SALIDA: Ejecución completada, datos en BD y archivos
